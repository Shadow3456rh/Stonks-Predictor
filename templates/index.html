Automated Pipeline Architecture

The pipeline executes in sequential stages on headless cloud runners, committing updated models and evaluation logs directly to the repository.

01

Market Ingestion

fetch_data.py

Pulls standardized OHLCV historical time-series for configured equities (AAPL, MSFT, GOOGL, AMZN, TSLA) using market data APIs, writing to data/raw_data.csv.

02

Feature Engineering

clean_data.py

Applies IQR statistical outlier filtering and constructs technical indicators: moving averages (5, 10, 20, 50), rolling volatility, daily returns, and high-low spreads.

03

Multi-Model Benchmarking

train_models.py

Trains Linear Regression, KNN, Decision Tree, Random Forest, and XGBoost across chronological splits. Evaluates RMSE, MAE, R², and inference latencies.

04

Champion Promotion

deploy_best_model.py

Evaluates leaderboard metrics against configurable promotion criteria (maximizing R²), promotes the winning artifact to deployed_model.pkl, and logs audit history.

Evaluated Regression Algorithms

Benchmarked concurrently during each pipeline run to ensure optimal out-of-sample generalization.

Linear Regression

Parametric Baseline

Standardized z-score normalization evaluating linear combinations across price momentum and volume indicators.

K-Nearest Neighbors

Instance-Based Memory

Identifies k=5 nearest historical market regimes based on normalized technical features using distance-weighted voting.

Decision Tree

Non-Linear Partitioning

Constructs interpretable orthogonal decision boundaries to segment price volatility regimes with bounded tree depth.

Random Forest

Bagging Ensemble

Averages 100 decorrelated decision trees, reducing variance and mitigating overfitting on volatile market series.

XGBoost

Gradient Boosting

Sequentially minimizes loss gradients with L1/L2 regularization for robust non-linear trend fitting.
