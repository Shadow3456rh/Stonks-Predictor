Automated ML Pipeline Flow

Each run executes autonomously on GitHub Actions runners, commits verified model artifacts back to the repository, and updates prediction services without requiring local machine uptime.

01
📡

Ingest Market Data

fetch_data.py

Pulls latest OHLCV market feeds via yfinance for configured equities (AAPL, MSFT, GOOGL, AMZN, TSLA). Standardizes schema and updates data/raw_data.csv and data/last_updated.txt.

02
🧹

Clean & Engineer Features

clean_data.py

Interpolates missing prices, bounds statistical outliers, and derives technical indicators: 5/10/20/50 MAs, daily returns, rolling volatility, and spreads. Generates eda_summary.json and correlation heatmap.

03
🧠

Train 5 Candidate Models

train_models.py

Trains Linear Regression, KNN, Decision Tree, Random Forest, and XGBoost over historical splits. Computes RMSE, MAE, R², and inference latencies into models/metrics.json.

04
🚀

Promote & Deploy Champion

deploy_best_model.py

Evaluates leaderboard metrics against configurable criteria (maximizing R² or minimizing RMSE). Promotes the winner to models/deployed_model.pkl and logs audit history in models/deployment_log.json.

Ensemble Candidate Models

Evaluated concurrently during each pipeline cycle to guarantee optimal predictive accuracy.

Linear Regression

Parametric Baseline

Scales features using standard z-score normalization to determine linear trend coefficients across moving averages and spreads.

K-Nearest Neighbors (KNN)

Instance-Based Memory

Finds k=5 closest historical market patterns based on normalized volatility and momentum indicators using inverse-distance weighting.

Decision Tree Regressor

Non-Linear Partitioning

Constructs interpretable orthogonal decision boundaries to segment price volatility regimes with bounded tree depth.

Random Forest Regressor

Bootstrap Bagging Ensemble

Aggregates 100 decorrelated decision trees, effectively reducing variance and resisting overfitting on volatile financial time-series.

XGBoost Regressor

Gradient Boosted Trees

Sequentially minimizes loss gradients with L1/L2 regularization for state-of-the-art non-linear predictive power.
